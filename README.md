
# Sweet Shop React App

This is a simple sweet shop web application built with React, Vite, HTML, and CSS.

## Features
- Homepage displaying a list of sweets
- Product detail page
- Cart feature

## How to Run

1. **Install dependencies** (if not already done):
   
	```powershell
	npm install
	```

2. **Start the development server:**
   
	```powershell
	npm run dev
	```
   
	The app will be available at the local address shown in the terminal (usually http://localhost:5173).

3. **Build for production:**
   
	```powershell
	npm run build
	```

4. **Preview the production build:**
   
	```powershell
	npm run preview
	```

---

Feel free to customize the sweets, styles, and features as needed!
